# WebTea HQ — design reference map

The WebTea HQ interface is a **synthesis**, not a copy of a single portfolio.

The source corpus is Emma Bostian's Developer Portfolios collection, which currently lists roughly 2,000 portfolios and exposes a machine-readable `feed.json`. citeturn0search2turn0search1

## Selected visual directions

| Reference direction | Source example | WebTea HQ treatment |
| --- | --- | --- |
| Old-school / retro portfolio | Akshat Kotpalliwar / IntegerAlex — https://realtalkportfolio.vercel.app | The People section becomes a 90s arcade-style player roster. |
| Animated frontend | Aakhand Tajmirul — listed as Animated | Motion language for transitions, hover states and section choreography. |
| GSAP / motion personality | Aman Rai — listed with GSAP animations | Used as inspiration for future motion modules, not copied. |
| 3D / game portfolio | Gil Itzhaky — listed as an Interactive 3D Portfolio Game | Used as a direction for future interactive product/project experiences. |
| Terminal / system portfolios | Multiple entries in the corpus | Reflected in the monospace labels, system IDs, status indicators and operational UI. |
| AI / agentic portfolios | Multiple AI and agentic-system entries | Translated into WebTea's AI employee layer: Hinata + Satoshi. |

## Design rule

We take **interaction patterns, composition ideas and visual archetypes** from the reference corpus, then rebuild them around WebTea HQ's own identity, information architecture and brand language.

We do not reproduce another creator's source code, branding, copy or unique visual artwork.
